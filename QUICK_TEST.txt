🔧 TROUBLESHOOTING

Issue: Connection refused
  → Check: redis-cli ping
  → Check: npm run dev in Terminal 1
  → Check: npm run worker:dev in Terminal 2

Issue: 500 Internal Server Error
  → Check server terminal for error logs
  → Check that Redis is running
  → Try with simpler request

Issue: Job stuck in "delayed"
  → Wait for retry delay (2-4 seconds)
  → Check worker terminal logs
  → This is expected behavior during retries

Issue: Job ID not found (404)
  → Copy exact job ID from submission response
  → Job may have been removed (removeOnComplete: true)
